# 0.1.0 测试记录

日期：2026-10-30。

## 范围

在 Rocky Linux 10.2 x86_64 VM 内创建独立安装目录，生成 Rocky 测试镜像，再使用分开的 Docker 容器测试安装、错误处理和离线使用。测试容器未挂载宿主机的 `/etc`、RPM 数据库或 Docker socket。测试后的软件包清单和软件源摘要与测试前一致，原有服务容器保持运行。

汇总为 **71 项检查：69 项通过，2 个镜像站不可用**。详细退出码见 [test-results.tsv](test-results.tsv)。这里的计数包含一次单元测试命令和一次 vet 命令；单元测试本身包含 21 个测试函数。

## 镜像可用性

| 镜像 | 本次结果 |
|---|---|
| Rocky 官方 | 元数据检查通过 |
| 阿里云 | 元数据检查通过，完成安装和仓库下载 |
| 清华 TUNA | Rocky 10 BaseOS 元数据地址返回 HTTP 404 |
| 中国科大 | Rocky 10 BaseOS 元数据地址返回 HTTP 403 |

程序保留这些镜像选项，检测失败时会说明原因，不将其作为可用源。可用性随镜像站和网络变化。

测试开始时 Docker 自动注入了不可用的代理，首次网络检查失败。清空测试容器的代理变量后重测。首次 SIGTERM 测试脚本同时关闭标准输入，存在竞争；汇总采用保留输入管道后重测的结果。原始日志保留，没有将这两次测试环境问题计为产品通过项。
