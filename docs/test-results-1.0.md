## 安全和资源回归

单元测试覆盖：JSON 重复键和大小写变体、未知字段、深度限制；Maven 自闭合 XML；pip 冒号语法及注释节标题；包源备份元数据篡改和手动编辑；归档路径穿越、链接、重复文件、校验失败、系统/架构不符、附加归档和不可信签名分支。

32 MiB RPM 流处理测试分别检查导出、检查、导入，每步累计分配小于 16 MiB。该指标针对回归样本，不代表任意归档的固定内存上限。

真实子进程输出测试保证版本检测不混入命令日志前缀，避免把真实 venv 误判为系统环境。独立代码审查的问题已补回归并修复。
