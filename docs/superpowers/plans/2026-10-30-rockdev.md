# Rockdev Implementation Plan

Execute inline in this session as authorized by user.

Goal: deliver a Go CLI and Linux binaries for the three requested workflows.
Architecture: internal/core owns system, plans and external process boundaries; internal/cli owns parsing and menu; cmd/rockdev is the executable.
Tech stack: Go >=1.22, standard library, DNF and createrepo_c on target.

## Global constraints
No host system changes, no shell evaluation, no VM success claims, dry runs make no writes. Package installs are not reversible transactions.

## Task 1: System and execution
- [ ] Add tests in internal/core/system_test.go for quoted os-release, rejected OS/versions/architectures, stopped execution and dry-run.
- [ ] Run go test ./internal/core and observe missing symbols.
- [ ] Implement system.go and runner.go; rerun tests.

## Task 2: Mirror configuration
- [ ] Add mirror_test.go exercising XML probes, exact managed sections, preservation, backups and failed refresh rollback.
- [ ] Run tests before implementation, implement mirror.go, rerun tests.

## Task 3: Local repository and environments
- [ ] Add plan tests for argument injection, installed dependency inclusion, signature verification and target isolation.
- [ ] Implement repo.go and environment.go after red tests; rerun tests.

## Task 4: CLI and delivery
- [ ] Add CLI tests for help, flags, confirmation, dry-run and invalid commands.
- [ ] Implement CLI and executable after red tests.
- [ ] Run go test ./..., go vet ./..., build Windows smoke executable and linux/amd64 + linux/arm64 binaries.
- [ ] Smoke help/menu/invalid-input and document VM acceptance commands, limitations and SHA256 artifacts.
