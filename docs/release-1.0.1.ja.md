# Rockdev 1.0.1

[中文](release-1.0.1.md) · [English](release-1.0.1.en.md) · 日本語

Rocky 8 のシステム Python は alternatives を経由して `/usr/libexec/platform-python3.6` を参照します。1.0.0 はこれを独自の実行環境と誤判定し、Python を含む明示的な一括更新を拒否していました。1.0.1 は標準の Python 起動パスに対して、この正確な参照先を許可します。ほかの libexec プログラム、独自ディレクトリ、分離環境の保護規則は維持します。

統合テストは pip の install コマンドが解析した index-url を確認し、pip 9 と新しい版に対応します。拒否テストは CLI の終了コード 1 を要求し、コマンド不足やタイムアウトを成功と扱いません。失敗項目があればスクリプトは非ゼロで終了します。

コマンド形式は従来どおりです。成果物は `dist/1.0.1/` に保存し、1.0.0 は残します。[1.0 操作説明](release-1.0.ja.md)と[再検証結果](test-results-1.0.1.ja.md)を参照してください。
