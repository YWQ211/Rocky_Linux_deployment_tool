# 0.1.0 テスト結果

[中文](test-results.md) · [English](test-results.en.md) · 日本語

実施日：**2026-10-30**。この翻訳は新たなテスト実施を示すものではありません。

## 検証範囲

Rocky Linux 10.2 x86_64 の VM 内に独立したインストール先を作成し、Docker イメージに取り込みました。インストール、エラー処理、オフライン利用は別々のコンテナで確認しました。ホストの `/etc`、RPM データベース、Docker socket はテストコンテナにマウントしていません。テスト前後でホストのパッケージ一覧とリポジトリ設定のハッシュは一致し、既存のサービスコンテナも稼働を継続しました。

**71 項目中 69 項目が成功、2 件はミラーが利用不可**でした。終了コードは [test-results.tsv](test-results.tsv) を参照してください。この件数には単体テストコマンドと vet コマンドが各 1 件含まれます。単体テスト自体は 21 個のテスト関数で構成されています。

## ミラーの状況

| ミラー | 実測結果 |
|---|---|
| Rocky 公式 | メタデータの確認に成功 |
| 阿里雲 | メタデータ確認、インストール、リポジトリ用ダウンロードに成功 |
| 清華大学 TUNA | Rocky 10 BaseOS のメタデータ URL が HTTP 404 |
| 中国科学技術大学 | Rocky 10 BaseOS のメタデータ URL が HTTP 403 |

利用できないミラーも選択肢には残しますが、確認時に理由を表示し、自動選択からは除外します。利用可否はミラーとネットワークの状態によって変わります。

開始時は Docker が利用できないプロキシを設定していました。テストコンテナ内のプロキシ変数を空にして再実行しています。最初の SIGTERM テストは標準入力を閉じる処理との競合があったため、集計には入力を開いたまま再実行した結果を使っています。元のログも保存しています。

## ビルドと未検証項目

- Windows：Go 1.27.1。21 個のテスト関数と `go vet` が成功。
- Linux：Rocky の Go 1.26.10。同じ単体テストと `go vet` が成功。
- Linux amd64/arm64、Windows amd64、英語・日本語が既定のビルドを作成。英語・日本語の amd64 版は実行済み。
- インストールとリポジトリの処理は多言語機能を追加したビルドで実行。最終ビルドでは言語の既定値、失敗ログ、権限、シグナル、Linux 単体テストも確認。
- Rocky 8、9 と ARM64 の実行は未検証。電源断、ディスク満杯、VM 全体の起動・復旧は模擬していません。
- 悪意のある RPM を実際に拒否するテストは未実施。署名なし・信頼できない署名の分岐には単体テストがあり、通常のダウンロード済み RPM は実際に署名を検証しています。

再実行用スクリプト：`scripts/integration.sh`、`scripts/integration-edge.sh`、`scripts/integration-final.sh`。元のログと停止済みコンテナは、テスト VM の `~/rockdev-isolated-tests/` に保存しています。
