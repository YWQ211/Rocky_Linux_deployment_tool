## 安全性とリソースの回帰試験

JSON の重複・大小文字違い・不明な項目・深い入れ子、Maven の自閉要素、pip のコロン構文とコメント付き節、バックアップ情報の改変と手動編集、アーカイブのパス逸脱・リンク・重複・ハッシュ不一致・環境不一致・追記アーカイブ・不正署名の分岐を単体テストで確認しています。

32 MiB の RPM を使ったストリーム処理の回帰試験では、出力・検査・入力の各操作の累計メモリ割当が 16 MiB 未満でした。すべての入力で固定メモリを保証する数値ではありません。

実プロセスの出力試験ではコマンドログを分離し、実際の venv の誤判定を防いでいます。独立レビューで見つかった問題は修正し、回帰試験を追加しました。

## 検証範囲

- Windows の Go テスト/vet、Linux amd64/arm64 と Windows amd64 のビルドが成功。Linux では Go 1.26.10 で同じテストを実行しました。
- 全体の導入処理は候補ビルドで実施し、最終ビルドで単体テスト、言語、混合設定、分離方針を再確認しました。
- ホストのパッケージ一覧とリポジトリのハッシュは不変で、既存サービスも正常でした。ホストの `/etc`、RPM データベース、Docker socket はマウントしていません。
- 実行検証は Rocky 10.2 x86_64 のみです。Rocky 8/9、ARM64、電源断、ディスク満杯は未検証です。
- 信頼済み RPM の署名を実際に確認しました。不正署名の拒否はテストランナーで確認し、不明な鍵は導入していません。
- 元の結果は VM の `~/rockdev-v1-tests/` に保存しています。[0.1 の結果](test-results.ja.md)は元の日付のままです。
